# PRODIGY_DS_04 

## Task 04 - Sentiment Analysis on Social Media Data

## Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion.

## Tools Used
- Python
- Pandas
- Matplotlib
- WordCloud

## Features
- Reads social media text data from a CSV file.
- Classifies sentiments (Positive, Negative, Neutral).
- Visualizes sentiment distribution using a bar chart.
- Generates a word cloud from the text data.
