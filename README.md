# 😊 PRODIGY INFOTECH – Data Science Internship Task 04

## 📌 Project Title

**Social Media Sentiment Analysis**

## 📖 Overview

This project analyzes and visualizes sentiment patterns in social media data to understand public opinion and attitudes toward different topics or brands. Using Python and data visualization techniques, the project classifies text into Positive, Negative, and Neutral sentiments and presents meaningful insights through charts and visual representations.

## 🎯 Objectives

* Analyze sentiment distribution in social media posts.
* Classify text into Positive, Negative, and Neutral categories.
* Visualize overall sentiment trends using bar charts.
* Generate a word cloud to identify the most frequently used words.
* Understand public opinion and user attitudes from textual data.
* Demonstrate basic Natural Language Processing (NLP) and data visualization techniques.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* WordCloud
* Jupyter Notebook

## 📂 Dataset

The analysis uses a **Social Media Sentiment Dataset** containing text posts labeled with their corresponding sentiments (Positive, Negative, or Neutral).

## 🔍 Key Insights

* Positive sentiments make up a significant portion of the analyzed posts.

* Neutral posts represent informational or balanced opinions.
* The word cloud reveals commonly used keywords across social media discussions.
* Visualizing sentiment data helps in understanding overall public perception and trends.

## ▶️ How to Run

1. Download or create the sentiment dataset and place it in the project folder.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib wordcloud
   ```

3. Open the Jupyter Notebook or Python script.
4. Run all cells or execute the script to generate the analysis and visualizations.
